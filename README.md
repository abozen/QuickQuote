# Teklif Oluşturucu

Bu proje, PDF dosyalarından ürün ve fiyat bilgilerini okuyarak otomatik teklif oluşturmanızı sağlayan bir web uygulamasıdır.

## Özellikler

- PDF dosyasından ürün ve fiyat bilgilerini otomatik çıkarma
- Manuel ürün ekleme ve düzenleme
- Sürükle-bırak ile ürün sıralamasını değiştirme
- KDV oranı ve fiyat artış oranı ayarlama
- Excel formatında dışa aktarma
- Modern ve responsive tasarım

## Teknolojiler

- Next.js 14
- TypeScript
- Material-UI
- PDF.js
- SheetJS (xlsx)
- React Beautiful DnD

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/yourusername/teklif-generator.git
cd teklif-generator
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

4. Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresini açın.

## Kullanım

1. Firma bilgilerinizi girin
2. PDF dosyası yükleyin veya manuel olarak ürün ekleyin
3. KDV oranı ve fiyat artış oranını ayarlayın
4. Ürünleri sürükle-bırak ile sıralayın
5. Teklifi Excel formatında dışa aktarın
